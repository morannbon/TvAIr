# TvAIr 1.3.0

## v1.3.0 の更新内容

- **予約・録画管理の保存構造を変更しました。** 旧版の予約データベースを引き継ぐ自動変換には対応していません。旧データを残したまま更新すると予約処理でエラーが発生するおそれがあります。このためv1.3.0ではクリーンインストールを推奨します。
- **チェーン予約の動作を改善しました。** 終了済みの予約が原因で誤って競合する問題を修正しました。チェーン予約をOFFにしても連結情報を保持します。ONへ戻すと元の連結を利用できます。OFF中の未開始予約は通常予約として扱います。連結の判定条件を録画開始から番組切替まで統一しました。
- **定時EPG取得の安定性を改善しました。** 制限時間内に完了できない場合は当日の予定を終了して録画前EPG確認の担当を更新します。その後も取得深度を浅くして当日中に完了できる場合は定時EPGの予定を復帰させます。
- **自動検索予約の対応環境を拡張しました。** ChSet.txtを使用しない環境でもBonDriverと`.ch2`から予約できるようにしました。
- **EPG取得や録画失敗時のエラー案内を改善しました。** 実際の原因と異なる案内が表示される問題を修正しました。原因を特定できない場合は推測せず処理結果を表示します。
- **「報告用コピー」を改善しました。** 長い記録も改行を含めて1回でコピーできます。問い合わせ用の記録を半角英数字へ変換する方式に変更しました。空白を含むファイルパスの保護も強化しました。
- チャンネル情報のサービスタイプを必須に戻しました。空欄の局は利用できません。TVTestで再スキャンしてください。
- 動作ログに他のアプリで開いている画面名が記録されないようにしました。
- その他軽微な修正。

### v1.3.0への移行

v1.3.0はクリーンインストールを推奨します。**TvAIrの設定・予約・自動検索ルール・録画履歴とAI-rhythmの統計が初期化されます。**

1. 録画とEPG取得が終わったらTvAIrを終了してください。TvAIrフォルダ全体をバックアップしてください。
2. TvAIrフォルダ内の**PluginsフォルダとB25Decoder.dll・winscard.dllなど自分で追加したファイルを残してください。** それ以外を削除してください。
3. **新しくビルドしたファイル一式を同じフォルダへ配置してください。**
4. TvAIrを起動して初期設定を行ってください。EPG取得後に予約と自動検索ルールを再設定してください。

## 製品説明

TvAIrはTVTest環境を利用して番組表から予約・録画・視聴までをまとめて扱うWindows向けアプリケーションです。自動検索予約・放送時間の変更への追従・複数チューナー・プラグインに対応します。

## 動作環境

### 実行環境

- Windows 10 / Windows 11（x64 / x86対応）
- .NET 8 Desktop Runtime
- Microsoft Visual C++ 再頒布可能パッケージ
- TVTest 0.10.0以降と使用するBonDriverおよびTVTestでチャンネルスキャン済みの `.ch2` ファイル（サービスタイプ必須）
- `ChSet.txt` は任意です。空欄時は選択したBonDriver名に対応する `.ch2` を読み込みます。
- 受信設備・対応チューナーとB25Decoder.dllまたは環境に応じた復号環境
- 録画ファイルを保存する空き容量

### ビルド環境

- Visual Studio 2022（C++によるデスクトップ開発とWindows SDK）
- .NET 8 SDK

## ビルド・配置

1. 配布ソースZIPを展開し `TvAIr.sln` をVisual Studio 2022で開きます。
2. 構成 `Release` と使用環境に適した `x64` または `x86` を選んでソリューション全体をビルドします。対象は `TvAIrEpgRec`・`AribDecodeBridge`・`TvAIrPlugin`・`TvAIr` の4プロジェクトです。
3. 主な出力先は `TvAIr\bin\x64\Release\net8.0-windows\` または `TvAIr\bin\x86\Release\net8.0-windows\` です。ビルド出力に含まれる `TvAIr.exe`・依存DLL・Web表示用ファイルなどをフォルダ構成ごと配置します。録画用 `TvAIrEpgRec.exe` と必要な依存ファイルも導入先へ揃えます。
4. `B25Decoder.dll` を使用する場合はTvAIrと同じアーキテクチャのものを `TvAIr.exe` と同じフォルダへ配置します。TVTestフォルダに `winscard.dll` がある場合はそのファイルを使用します。ない場合はWindows標準のカードリーダー機能を読み込みます。カードとの通信はB25デコーダー側の機能です。
5. TVTest 0.10.0以降で利用する放送波のチャンネルスキャンを完了してから `TvAIr.exe` を起動します。TVTest・BonDriver・チャンネル・録画保存先を設定してください。EPG取得後に番組表を確認して短い視聴・録画テストを行ってください。

ビルド不要の実行用ZIPを利用する場合は同梱の `INSTALL.txt` にも従ってください。

TvAIrを終了・再起動しても視聴中のTVTestは終了しません。再起動後の視聴操作では新しいTVTestを起動します。「視聴停止」を選んだ場合はその操作対象のTVTestを終了します。

## 基本的な使い方・設定

- 番組表から録画予約を追加できます。プログラム予約・自動検索予約・連続番組のチェーン予約も利用できます。
- 設定の「チェーン予約」で無効・手動・自動を選択できます。自動では同じ局で終了・開始時刻が一致する予約を接続します。録画中の「今すぐ録画」も条件を満たせば接続対象です。各番組は別々のTSファイルへ保存します。
- 自動検索予約のルールごとに「現在のサービスのみ保存する」「字幕データを保存する」を設定できます。
- 定時EPG取得は録画予約との重複に応じて開始時刻を調整します。録画前・録画中の番組情報確認により放送時間が変更された場合の追従を行います。
- 録画用と視聴用で別のTVTestを利用できます。視聴専用のTVTestを使う場合は「視聴用TVTest.exe のフルパス」を設定します。
- CATVなどでChSet.txtがない場合は空欄にして使用するBonDriver名と一致する `.ch2` を配置します。ケーブルテレビ用のBonDriverはチューナー設定の「CATV」を選択できます。既に「地デジ/BS/CS」で動作している設定も引き続き利用できます。局は地上波・BS・CS・CATVに分類して表示します。

自動チェーンの(C)は先頭から最後まで表示します。手動チェーンでは2番組目から最後まで表示します。方式を切り替えても作成済みのチェーンは残ります。無効にすると未開始の予約は通常予約として扱います。再度有効にすると保存済みの連結が戻ります。開始済みの連続録画は途中で停止しません。

### チャンネル情報の変更

ChSet.txtを空欄にした場合は選択したBonDriverと同じ名前の `.ch2` を使います。BonDriverフォルダを先に探して次にTVTestフォルダを探します。TVTest 0.10.0以降でのチャンネルスキャンは必須です。サービスタイプが空欄の局は利用できません。TVTestで再スキャンすると `.ch2` の局名や選局情報を更新できます。ChSet.txtの使用有無を切り替えた際は設定を保存し再起動してください。ONID・TSID・SIDが変わる場合はEPGを取り直して既存予約を確認してください。旧番号の予約は自動移行しません。

### ネットワーク利用

「ネットワーク利用」の初期状態はOFFです。OFF時はLAN・インターネット通信を利用せずこのPC内でTvAIrを使用します。LAN内端末から接続するには「ネットワーク利用」と「LANからの接続を許可する」を順にONにして12文字以上の接続用パスワードを設定・保存してください。パスワードの大文字・小文字は区別されます。インターネットに直接ポートを公開しないでください。

外部情報を利用するプラグインには最上位の「ネットワーク利用」ONに加えプラグインごとのインターネット利用許可が必要です。最上位OFF時は下位の許可設定に関わらず外部通信を停止します。

- CATV（ISDB-C）は利用者から実カードでの復号・録画とAIrCon経由の視聴成功が報告されています。使用するチューナーやBonDriverによって動作条件が異なります。

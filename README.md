# TvAIr 1.2.14

## v1.2.14 の更新内容

- **自動チェーン予約を追加しました。** 同じ局で終了・開始時刻が一致する予約を自動接続します。従来の手動方式も選択できます。
- **番組表から放送中の番組を視聴できるようになりました（AIrCon必須）。** AIrConを導入・有効化し、視聴操作とプラグイン画面の利用を許可してください。対象局を受信できる視聴用チューナーとTVTestの設定が必要です。設定のない放送波には「視聴」ボタンを表示しません。
- **番組表に左右の横移動ボタンを追加しました。** クリックで横移動、長押しで連続移動、ダブルクリックで左右の端へ移動できます。
- **局名セルのダブルクリックに対応しました。** 選んだ局の番組欄が画面中央に来るよう横移動します。
- **放送時間の変更への追従を改善しました。** 延長・早期終了に合わせて録画終了時刻を更新し、チェーンの後続番組にも時刻変更を反映します。先頭番組の録画終了後に、後続番組の終了判定ができなくなる問題も修正しました。
- その他軽微な修正。

## 製品説明

TvAIrはTVTest環境を利用し、番組表から予約・録画・視聴までをまとめて扱うWindows向けアプリケーションです。自動検索予約、放送時間の変更への追従、複数チューナー、プラグインに対応します。

## 動作環境

### 実行環境

- Windows 10 / Windows 11（x64 / x86対応）
- .NET 8 Desktop Runtime
- Microsoft Visual C++ 再頒布可能パッケージ
- TVTest 0.10.0以降、使用するBonDriver、TVTest用 `.ch2` ファイル
- `ChSet.txt` は任意です。空欄時は選択したBonDriver名に対応する `.ch2` を読み込みます。
- 受信設備・対応チューナーとB25Decoder.dllまたは環境に応じた復号環境
- 録画ファイルを保存する空き容量

### ビルド環境

- Visual Studio 2022（C++によるデスクトップ開発、Windows SDK）
- .NET 8 SDK

## ビルド・配置

1. 配布ソースZIPを展開し `TvAIr.sln` をVisual Studio 2022で開きます。
2. 構成 `Release`、使用環境に適した `x64` または `x86` を選んでソリューション全体をビルドします。対象は `TvAIrEpgRec`、`AribDecodeBridge`、`TvAIrPlugin`、`TvAIr` の4プロジェクトです。
3. 主な出力先は `TvAIr\bin\x64\Release\net8.0-windows\` または `TvAIr\bin\x86\Release\net8.0-windows\` です。ビルド出力に含まれる `TvAIr.exe`、依存DLL、Web表示用ファイルなどをフォルダ構成ごと配置します。録画用 `TvAIrEpgRec.exe` と必要な依存ファイルも導入先へ揃えます。
4. `B25Decoder.dll` を使用する場合はTvAIrと同じアーキテクチャのものを `TvAIr.exe` と同じフォルダへ配置します。TVTestフォルダに `winscard.dll` があればそれを使い、なければWindows標準のカードリーダー機能を読み込みます。カードとの通信はB25デコーダー側の機能です。
5. `TvAIr.exe` を起動し、TVTest、BonDriver、チャンネル、録画保存先を設定します。EPG取得後に番組表を確認し、短い視聴・録画テストを行ってください。

ビルド不要の実行用ZIPを利用する場合は、同梱の `INSTALL.txt` にも従ってください。

TvAIrを終了・再起動しても、視聴中のTVTestは終了しません。再起動後の視聴操作では新しいTVTestを起動します。「視聴停止」を選んだ場合は、その操作対象のTVTestを終了します。

## 基本的な使い方・設定

- 番組表から録画予約を追加できます。プログラム予約、自動検索予約、連続番組のチェーン予約も利用できます。
- 設定の「チェーン予約」で無効・手動・自動を選択できます。自動では同じ局で終了・開始時刻が一致する予約を接続します。録画中の「今すぐ録画」も条件を満たせば接続対象です。各番組は別々のTSファイルへ保存します。
- 自動検索予約のルールごとに「現在のサービスのみ保存する」「字幕データを保存する」を設定できます。
- 定時EPG取得は録画予約との重複に応じて開始時刻を調整します。録画前・録画中の番組情報確認により、放送時間が変更された場合の追従を行います。
- 録画用と視聴用で別のTVTestを利用できます。視聴専用のTVTestを使う場合は「視聴用TVTest.exe のフルパス」を設定します。
- CATVなどでChSet.txtがない場合は空欄にし、使用するBonDriver名と一致する `.ch2` を配置します。ケーブルテレビ用のBonDriverはチューナー設定の「CATV」を選択できます。既に「地デジ/BS/CS」で動作している設定も引き続き利用できます。局は地上波・BS・CS・CATVに分類して表示します。

自動チェーンの(C)は先頭から最後まで、手動チェーンでは2番組目から最後まで表示します。方式を切り替えても作成済みのチェーンは残り、表示と予約取消は現在選択中の方式に従います。

### チャンネル情報の変更

ChSet.txtを空欄にした場合は選択したBonDriverと同じ名前の `.ch2` を使います。BonDriverフォルダを先に探し、次にTVTestフォルダを探します。TVTestでチャンネルを再スキャンし `.ch2` を更新すると局名や選局情報を更新できます。ChSet.txtの使用有無を切り替えた際は設定を保存し再起動してください。ONID・TSID・SIDが変わる場合はEPGを取り直し、既存予約を確認してください。旧番号の予約は自動移行しません。

### ネットワーク利用

「ネットワーク利用」の初期状態はOFFです。OFF時はLAN・インターネット通信を利用せず、このPC内でTvAIrを使用します。LAN内端末から接続するには「ネットワーク利用」と「LANからの接続を許可する」を順にONにし、12文字以上の接続用パスワードを設定・保存してください。パスワードの大文字・小文字は区別されます。インターネットに直接ポートを公開しないでください。

外部情報を利用するプラグインには最上位の「ネットワーク利用」ONに加えプラグインごとのインターネット利用許可が必要です。最上位OFF時は下位の許可設定に関わらず外部通信を停止します。

## 更新方法

1. 録画・EPG取得・視聴が実行中でないことを確認し、TvAIrを終了します。
2. 現在のTvAIrフォルダと設定・予約・録画履歴・プラグイン保存データをバックアップします。
3. 同じアーキテクチャでビルドした新しいファイル群へ差し替えます。保存データは削除しません。
4. 再起動後、チューナー設定・番組表・予約リスト・録画保存先を確認し、短いテスト録画を行います。
5. v1.2.0～v1.2.2から更新した場合は設定の自動移行に伴い再起動案内が出ることがあります。その場合は案内に従って一度再起動してください。

## 注意事項

- CATV（ISDB-C）は利用者から実カードでの復号・録画とAIrCon経由の視聴成功が報告されています。使用するチューナーやBonDriverによって動作条件が異なります。
- 使用するチューナー、BonDriver、TVTest、カードとその契約、チャンネル設定により動作が変わります。復号器の初期化に失敗すると暗号化されたまま保存される場合があります。「現在のサービスのみ保存する」で録画した未復号ファイルは後から復号できない場合があります。
- 録画の開始・終了追従は放送波の番組情報と受信状況に依存します。重要な予約は事前に確認してください。
- 録画中断後、録画可能時間が残っていれば残り区間を別ファイルで再開する場合があります。手動停止や録画失敗などの場合、設定済みの録画終了後の電源操作は行われません。
- 更新時は既存の設定・録画履歴・予約・プラグインデータのバックアップを推奨します。
- TvAIrの使用による録画失敗やデータ損失等について、作者は責任を負いません。

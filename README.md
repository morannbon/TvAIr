# TvAIr 1.2.7

## v1.2.7 の更新内容

- 仮想winscard.dllを使用しない環境で、Windows標準のカードリーダー機能を読み込むようにしました。
- x86版でB25デコーダーを呼び出す際の不具合を修正しました。
- その他軽微な修正。

---

TvAIrは普段使っているTVTest環境を活かして番組表から予約・録画・視聴までまとめて扱うWindows向けアプリケーションです。

番組表で見つけた番組をその場で予約できます。予約状況や録画状態もTvAIr上で確認できます。繰り返し録画したい番組は自動検索予約に任せます。必要なときはTVTestでそのまま視聴できます。

## 主な機能

- 番組表からの録画予約・プログラム予約・チェーン予約
- キーワードによる自動検索予約
- 予約・録画・競合状態の確認と操作
- 番組開始・終了時刻の変更への追従
- TVTestを利用した視聴
- 地上波 / BS / CSと複数チューナーの利用
- 定時EPG取得と録画前・録画中の番組情報確認
- TvAIr対応プラグインによる機能追加
- ライト / ダークテーマ
- 同一PC内での利用または設定によるLAN内端末からの利用

## 動作環境

### 実行環境

- Windows 10 / Windows 11
- .NET 8 Desktop Runtime
- Microsoft Visual C++ 再頒布可能パッケージ
- TVTest 0.10.0以降を利用できる環境
- 使用するBonDriver
- TVTest用の `.ch2` ファイル
- `ChSet.txt`（任意。空欄時はBonDriver名に対応するch2で選局します）
- B25デコーダーまたは受信環境に応じた復号環境
- 録画ファイルを保存できる十分な空き容量

### ビルド環境

- Visual Studio 2022
- .NET 8 SDK
- Visual Studio 2022 の「C++によるデスクトップ開発」

TvAIr 1.2.7は `x64` / `x86` の両方を対象としています。

## ビルド方法

1. 配布ZIPを任意のフォルダへ展開します。
2. Visual Studio 2022で `TvAIr.sln` を開きます。
3. ソリューション構成を `Release` にします。
4. 使用する環境に合わせて `x64` または `x86` を選択します。
5. ソリューション全体をビルドします。

ソリューションは次の4プロジェクトで構成されています。

- `TvAIrEpgRec`
- `AribDecodeBridge`
- `TvAIrPlugin`
- `TvAIr`

通常はソリューション全体をビルドしてください。

主な出力先は次のとおりです。

- x64: `TvAIr\bin\x64\Release\net8.0-windows\`
- x86: `TvAIr\bin\x86\Release\net8.0-windows\`

## インストール方法

1. TvAIrを起動している場合は終了します。
2. 使用するアーキテクチャでReleaseビルドした `TvAIr` の出力フォルダ一式を任意の利用フォルダへ配置します。
3. `B25Decoder.dll` が必要な環境では `TvAIr.exe` と同じフォルダへ配置します。
4. `TvAIr.exe` を起動します。
5. 設定画面でTVTest・BonDriver・チャンネル定義・録画保存先を設定します。ISDB-CではChSet.txtを空欄にし、TVTestで生成したBonDriver名と同名のch2をTVTestまたはBonDriverフォルダに置きます。追加のch2入力は不要です。PT3の既存設定も使用できます。
6. EPGを取得して番組表が表示されることを確認します。
7. 初回利用時は短いテスト録画を行って録画ファイルが正常に作成されることを確認してください。

録画用と視聴用でTVTestを分けない場合は基準として指定したTVTestを共通で使用できます。視聴専用のTVTestを別に使用する場合は設定画面の「視聴用TVTest.exe のフルパス」を指定してください。

## 基本的な使い方

### 番組表と録画予約

EPG取得後に番組表から番組を選んで録画予約できます。予約リストでは登録済み予約・録画中の番組・競合している予約を確認できます。

通常の番組予約のほか時刻を指定するプログラム予約と条件に合う番組を自動で予約する自動検索予約を利用できます。

### チェーン予約

同じ放送局で連続する番組を録画する場合は「前番組を優先する」または「後番組を優先する」から録画方法を選べます。

チェーン予約は「後番組を優先する」を選んだ場合に利用できるオプションです。同じ放送局で連続する番組を前後とも欠損なく録画します。各番組はマージンを確保した別のTSファイルとして保存します。

利用する場合は「設定」→「録画」で「後番組を優先する」と「チェーン予約を実行する」を有効にします。チェーン予約した番組は予約リストに `(C)` が表示されます。

チェーン予約を無効にしても未開始の予約は削除されず通常予約として残ります。録画中の番組は設定変更だけでは中断しません。

### EPG取得

定時EPG取得は録画予約と重なる場合に開始時刻を調整します。設定した時刻から最大3時間の範囲で必要な取得時間を確保できる時間帯へ自動でずらします。

取得深度は120秒 / 180秒 / 240秒 / 300秒から選択できます。

録画前の番組情報確認を有効にすると録画開始前に番組情報を確認します。放送時間の変更が分かった場合は録画予定へ反映します。録画中に終了時刻の変更が分かった場合も追従します。

### 自動検索予約

番組名などの条件を登録しておくと条件に合う番組を自動で予約できます。

検索ルールごとに「現在のサービスのみ保存する」と「字幕データを保存する」を指定できます。TVTest全体の録画設定を切り替えずに番組の種類や用途に合わせて録画内容を使い分けられます。

### 視聴

TvAIrからTVTestを起動して視聴できます。録画用と視聴用で別のTVTestを使うこともできます。

## ネットワーク利用

初期状態では「ネットワーク利用」はOFFです。この状態ではTvAIrは外部ネットワークやLANを利用せずこのPC内で使用します。

同じLAN内の別端末からTvAIrを利用する場合は設定画面の「ネットワーク」で次の項目を設定してください。

1. 「ネットワーク利用」をONにします。
2. 「LANからの接続を許可する」をONにします。
3. 12文字以上の接続用パスワードを設定します。
4. 設定を保存します。

接続用パスワードはWindowsのユーザー名やパスワードとは別のものです。大文字と小文字は区別されます。

TvAIrをインターネットへ直接公開する用途は想定していません。ルーター等でTvAIrの待受ポートをインターネットへ直接公開しないでください。

インターネット接続に対応したプラグインを利用する場合は「ネットワーク利用」をONにしたうえでプラグインごとのインターネット利用許可を設定します。「ネットワーク利用」がOFFの間はプラグインごとの設定にかかわらずインターネット接続も行いません。

## プラグイン

TvAIr対応プラグインを追加すると推薦・視聴支援・番組情報表示など必要な機能を追加できます。

導入方法や設定は各プラグインのREADMEを確認してください。インターネットを利用するプラグインはTvAIrのネットワーク設定とプラグインごとの許可に従います。

## 録画中断時の扱い

録画中にWindowsのスリープ・TvAIrの終了・PCの再起動などで録画処理が失われた場合はその区間を失敗として確定します。

その後も録画可能な時間が残っている場合は残り区間を別の録画として再開する場合があります。

## 録画終了後の電源操作

録画終了後にスリープまたはシャットダウンする設定では最後に残っている録画が正常に完了した場合に電源操作の待機へ入ります。

次の場合は電源操作を行いません。

- 録画を手動で停止した場合
- 録画が失敗した場合
- 待機中に別の録画やEPG取得が始まった場合
- TvAIrで視聴中の場合
- 次の録画やEPG取得に必要な起床準備時間へ入った場合

## 更新方法

旧バージョンから更新する場合は次の手順を推奨します。

1. 録画中・EPG取得中・視聴中でないことを確認します。
2. TvAIrを終了します。
3. 現在使用しているTvAIrフォルダを必要に応じてバックアップします。
4. 新しいバージョンを同じアーキテクチャでReleaseビルドします。
5. 新しいビルド出力でアプリ本体を更新します。
6. TvAIrを起動して設定・番組表・予約リスト・録画保存先を確認します。
7. 可能であれば短いテスト録画を行ってください。

更新時に設定や既存データを初期化する必要はありません。既存環境を保持したまま更新する場合でも重要な設定やデータは事前にバックアップしておくことを推奨します。

### チャンネル情報の更新

ChSet.txtを空欄にした場合は、選択したBonDriverと同じ名前のch2ファイルを読み込みます。BonDriverフォルダを先に探し、見つからない場合はTVTestフォルダを探します。TVTestでチャンネルを再スキャンして同じファイルを更新すると、次のチャンネル読込みで局名や選局情報に反映します。

ChSet.txtの使用有無を切り替えた場合は設定を保存して再起動してください。局の識別番号（ONID・TSID・SID）が変わる移動では、EPGを取得し直して既存の予約を確認してください。旧識別番号の予約は自動移行しません。

### 復号に必要な条件

B25Decoder.dllはTvAIrと同じアーキテクチャのものを使用してください。指定したTVTestフォルダにwinscard.dllがあればそちらを読み込みます。なければWindows標準のカードリーダー機能を読み込みます。カードリーダーの選択とカード通信はB25デコーダーが行います。

復号器の初期化に失敗した場合は暗号化されたまま保存されることがあります。「現在のサービスのみ保存する」で作成した未復号ファイルは、後から復号できない場合があります。今回の変更で過去の録画ファイルを修復することはできません。

ISDB-Cの実受信と実カードでの復号は開発側では未確認です。

# TvAIr 1.2.3

## 重要事項：TvAIr.ini の再編

TvAIr 1.2.3では、今後の設定管理を安定させるため、TvAIr本体の設定ファイル `TvAIr.ini` の構成を整理しました。

v1.2.0～v1.2.2から更新した場合は設定を自動移行します。初回起動時に案内が表示されたら、TvAIrを一度再起動してください。

既存の設定・予約・録画履歴などはそのまま引き継がれます。`TvAIr.ini` を手動で編集する必要はありません。

v1.2.0～v1.2.2のどの版からでも直接更新できます。

## v1.2.3 の主な変更

- 番組延長時に録画が途中終了して再開される不具合を修正しました。
- キーワード検索で無効になっているチャンネルの番組が表示される不具合を修正しました。
- 無効になっているチャンネルの予約が録画対象になる不具合を修正しました。
- 番組表・検索処理のメモリ消費量を削減しました。
- 長時間利用時の安定性を改善しました。

---

TvAIrは普段使っているTVTest環境を活かし、番組表から予約・録画・視聴までまとめて扱うWindows向けアプリケーションです。

番組表で見つけた番組をその場で予約できます。予約状況や録画状態もTvAIr上で確認できます。繰り返し録画したい番組は自動検索予約に任せ、必要なときはTVTestでそのまま視聴できます。

## 主な機能

- 番組表からの録画予約、プログラム予約、チェーン予約
- キーワードによる自動検索予約
- 予約・録画・競合状態の確認と操作
- 番組開始・終了時刻の変更への追従
- TVTestを利用した視聴
- 地上波 / BS / CSと複数チューナーの利用
- 定時EPG取得と録画前・録画中の番組情報確認
- TvAIr対応プラグインによる機能追加
- ライト / ダークテーマ
- 同一PC内での利用、または設定によるLAN内端末からの利用

## 動作環境

### 実行環境

- Windows 10 / Windows 11
- .NET 8 Desktop Runtime
- Microsoft Visual C++ 再頒布可能パッケージ
- TVTest 0.10.0以降を利用できる環境
- 使用するBonDriver
- TVTest用の `.ch2` ファイル
- `ChSet.txt`
- B25デコーダー、または受信環境に応じた復号環境
- 録画ファイルを保存できる十分な空き容量

### ビルド環境

- Visual Studio 2022
- .NET 8 SDK
- Visual Studio 2022 の「C++によるデスクトップ開発」

TvAIr 1.2.3は `x64` / `x86` の両方を対象としています。

## ビルド方法

1. 配布ZIPを任意のフォルダへ展開します。
2. Visual Studio 2022で `TvAIr.sln` を開きます。
3. ソリューション構成を `Release` にします。
4. 使用する環境に合わせて `x64` または `x86` を選択します。
5. ソリューション全体をビルドします。

ソリューションは次の4プロジェクトで構成されています。

- `TvAIrEpgRec`
- `AribDecodeBridge`
- `TvAIrPlugin`
- `TvAIr`

通常はソリューション全体をビルドしてください。

主な出力先は次のとおりです。

- x64: `TvAIr\bin\x64\Release\net8.0-windows\`
- x86: `TvAIr\bin\x86\Release\net8.0-windows\`

## インストール方法

1. TvAIrを起動している場合は終了します。
2. 使用するアーキテクチャでReleaseビルドした `TvAIr` の出力フォルダ一式を任意の利用フォルダへ配置します。
3. `B25Decoder.dll` が必要な環境では `TvAIr.exe` と同じフォルダへ配置します。
4. `TvAIr.exe` を起動します。
5. 設定画面で基準となるTVTest、使用するBonDriver、`.ch2`、`ChSet.txt`、録画保存先などを設定します。
6. EPGを取得して番組表が表示されることを確認します。
7. 初回利用時は短いテスト録画を行い、録画ファイルが正常に作成されることを確認してください。

録画用と視聴用でTVTestを分けない場合は、基準として指定したTVTestを共通で使用できます。視聴専用のTVTestを別に使用する場合は、設定画面の「視聴用TVTest.exe のフルパス」を指定してください。

## 基本的な使い方

### 番組表と録画予約

EPG取得後に番組表から番組を選んで録画予約できます。予約リストでは登録済み予約、録画中の番組、競合している予約を確認できます。

通常の番組予約のほか、時刻を指定するプログラム予約と条件に合う番組を自動で予約する自動検索予約を利用できます。

### チェーン予約

同じ放送局で連続する番組を録画する場合は「前番組を優先する」または「後番組を優先する」から録画方法を選べます。

チェーン予約は「後番組を優先する」を選んだ場合に利用できるオプションです。同じ放送局で連続する番組を前後とも欠損なく録画し各番組をマージンを確保した別のTSファイルとして保存します。

利用する場合は「設定」→「録画」で「後番組を優先する」と「チェーン予約を実行する」を有効にします。チェーン予約した番組は予約リストに `(C)` が表示されます。

チェーン予約を無効にしてもまだ始まっていない予約は削除されず通常予約として残ります。録画中の番組は設定変更だけでは中断しません。

### EPG取得

定時EPG取得は録画予約と重なる場合に開始時刻を調整します。設定した時刻から最大3時間の範囲で必要な取得時間を確保できる時間帯へ自動でずらします。

取得深度は120秒 / 180秒 / 240秒 / 300秒から選択できます。

録画前の番組情報確認を有効にすると開始前に番組情報を確認します。放送時間の変更が分かった場合は録画予定へ反映します。録画中に終了時刻の変更が分かった場合も追従します。

### 自動検索予約

番組名などの条件を登録しておくと、条件に合う番組を自動で予約できます。

検索ルールごとに「現在のサービスのみ保存する」と「字幕データを保存する」を指定できます。TVTest全体の録画設定を切り替えず、番組の種類や用途に合わせて録画内容を使い分けられます。

### 視聴

TvAIrからTVTestを起動して視聴できます。録画用と視聴用で別のTVTestを使うこともできます。

## ネットワーク利用

初期状態では「ネットワーク利用」はOFFです。この状態ではTvAIrは外部ネットワークやLANを利用せず、このPC内で使用します。

同じLAN内の別端末からTvAIrを利用する場合は、設定画面の「ネットワーク」で次の項目を設定してください。

1. 「ネットワーク利用」をONにします。
2. 「LANからの接続を許可する」をONにします。
3. 12文字以上の接続用パスワードを設定します。
4. 設定を保存します。

接続用パスワードはWindowsのユーザー名やパスワードとは別のものです。大文字と小文字は区別されます。

TvAIrをインターネットへ直接公開する用途は想定していません。ルーター等でTvAIrの待受ポートをインターネットへ直接公開しないでください。

インターネット接続に対応したプラグインを利用する場合は「ネットワーク利用」をONにしたうえで、プラグインごとのインターネット利用許可を設定します。「ネットワーク利用」がOFFの間はプラグインごとの設定にかかわらずインターネット接続も行いません。

## プラグイン

TvAIr対応プラグインを追加すると、推薦、視聴支援、番組情報表示など必要な機能を追加できます。

導入方法や設定は各プラグインのREADMEを確認してください。インターネットを利用するプラグインはTvAIrのネットワーク設定とプラグインごとの許可に従います。

## 録画中断時の扱い

録画中にWindowsのスリープ、TvAIrの終了、PCの再起動などで録画処理が失われた場合、その区間は失敗として確定します。

その後も録画可能な時間が残っている場合は残り区間を別の録画として再開する場合があります。

## 録画終了後の電源操作

録画終了後にスリープまたはシャットダウンする設定では、最後に残っている録画が正常に完了した場合に電源操作の待機へ入ります。

次の場合は電源操作を行いません。

- 録画を手動で停止した場合
- 録画が失敗した場合
- 待機中に別の録画やEPG取得が始まった場合
- TvAIrで視聴中の場合
- 次の録画やEPG取得に必要な起床準備時間へ入った場合

## 更新方法

旧バージョンから更新する場合は次の手順を推奨します。

1. 録画中、EPG取得中、視聴中でないことを確認します。
2. TvAIrを終了します。
3. 現在使用しているTvAIrフォルダを必要に応じてバックアップします。
4. 新しいバージョンを同じアーキテクチャでReleaseビルドします。
5. 新しいビルド出力でアプリ本体を更新します。
6. TvAIrを起動して設定、番組表、予約リスト、録画保存先を確認します。
7. 可能であれば短いテスト録画を行ってください。

更新時に設定や既存データを初期化する必要はありません。既存環境を保持したまま更新する場合でも、重要な設定やデータは事前にバックアップしておくことを推奨します。

## 注意事項

- 録画やEPG取得を安定して行うためTVTest、BonDriver、チャンネル設定を使用環境に合わせて正しく設定してください。
- チューナー構成、BonDriver、TVTest、録画保存先などを変更した場合は短いテスト録画で動作確認することを推奨します。
- 録画中やEPG取得中は一部の設定を変更できない場合があります。
- 予約録画や定時EPG取得を常時利用する場合はWindows起動時の自動起動やスリープ復帰設定を必要に応じて利用してください。
- 本ソフトウェアの使用により発生した録画失敗、録画データの欠損、設定ファイルやデータベースの破損、既存環境への影響、その他の損害について作者は責任を負いません。

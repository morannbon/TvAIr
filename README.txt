# TvAIr 1.2.1

TvAIrは、TVTestを利用してテレビ番組の番組表表示、録画予約、自動検索予約、視聴、EPG取得、プラグイン連携を行うWindows向けアプリケーションです。

## 主な機能

- 番組表の表示と番組情報の確認
- 番組表からの録画予約、プログラム予約、チェーン予約
- キーワード検索と自動検索予約
- 予約状態、録画状態、競合状態の確認と操作
- TVTestを利用したテレビ視聴
- 定時EPG取得と録画前の番組情報確認
- 録画中の番組情報更新への追従
- TvAIr対応プラグインの利用
- ライト／ダークテーマ
- 同一PC内での利用、および設定によりLAN内端末からの利用

## 動作環境

### 実行環境

- Windows 10 / Windows 11
- .NET 8 Desktop Runtime
- Microsoft Visual C++ 再頒布可能パッケージ
- TVTest 0.10.0以降を利用できる環境
- 使用するBonDriver
- TVTest用の `.ch2` ファイル
- `ChSet.txt`
- B25デコーダー、または受信環境に応じた復号環境
- 録画ファイルを保存できる十分な空き容量

### ビルド環境

- Visual Studio 2022
- .NET 8 SDK
- Visual Studio 2022 の「C++によるデスクトップ開発」

TvAIr 1.2.1は `x64` / `x86` の両方を対象としています。

## ビルド方法

1. 配布ZIPを任意のフォルダへ展開します。
2. Visual Studio 2022で `TvAIr.sln` を開きます。
3. ソリューション構成を `Release` にします。
4. 使用する環境に合わせて `x64` または `x86` を選択します。
5. ソリューション全体をビルドします。

ソリューションは次の4プロジェクトで構成されています。

- `TvAIrEpgRec`
- `AribDecodeBridge`
- `TvAIrPlugin`
- `TvAIr`

通常はソリューション全体をビルドしてください。

主な出力先は次のとおりです。

- x64: `TvAIr\bin\x64\Release\net8.0-windows\`
- x86: `TvAIr\bin\x86\Release\net8.0-windows\`

## インストール方法

1. TvAIrを起動している場合は終了します。
2. 使用するアーキテクチャでReleaseビルドした `TvAIr` の出力フォルダ一式を、任意の利用フォルダへ配置します。
3. `B25Decoder.dll` が必要な環境では、`TvAIr.exe` と同じフォルダへ配置します。
4. `TvAIr.exe` を起動します。
5. 設定画面で、基準となるTVTest、使用するBonDriver、`.ch2`、`ChSet.txt`、録画保存先などを設定します。
6. EPGを取得し、番組表が表示されることを確認します。
7. 初回利用時は短いテスト録画を行い、録画ファイルが正常に作成されることを確認してください。

録画用と視聴用でTVTestを分けない場合は、基準として指定したTVTestを共通で使用できます。視聴専用のTVTestを別に使用する場合は、設定画面の「視聴用TVTest.exe のフルパス」を指定してください。

## 基本的な使い方

### 番組表と録画予約

EPG取得後、番組表から番組を選択して録画予約できます。予約一覧では、登録済み予約の確認、無効化・有効化、録画停止などを行えます。

番組表から通常の番組予約を行うほか、時刻を指定するプログラム予約、条件に一致した番組を自動的に予約する自動検索予約を利用できます。

### チェーン予約

チェーン予約は、同じ放送局で連続する複数番組を、同じ録画用チューナーで順番に録画するための機能です。

前後の録画マージンが重なる場合は後番組の開始を優先します。チェーン対象となった前番組には `(C)` が表示されます。

### EPG取得

定時EPG取得は、設定した開始時刻を基準として、録画予約と重ならず必要な取得時間を確保できる時間帯へ自動調整されます。

録画前の番組情報確認を有効にすると、録画開始前に最新の番組情報を確認し、放送時刻の変更へ追従します。確認できなかった場合でも、予定された録画時刻になれば録画を開始します。

録画中も番組情報の更新を確認し、番組終了時刻の変更へ追従します。

### 視聴

TvAIrからTVTestを起動して視聴できます。録画用と視聴用のTVTestを分けて設定することもできます。

TvAIrから起動した視聴用TVTestを終了すると、使用していた視聴用チューナーは解放されます。

## ネットワーク利用

初期状態では「ネットワーク利用」はOFFです。この状態では、TvAIrは外部ネットワークやLANを利用せず、このPC内で使用します。

同じLAN内の別端末からTvAIrを利用する場合は、設定画面の「ネットワーク」で次の項目を設定してください。

1. 「ネットワーク利用」をONにします。
2. 「LANからの接続を許可する」をONにします。
3. 12文字以上の接続用パスワードを設定します。
4. 設定を保存します。

接続用パスワードはWindowsのユーザー名やパスワードとは別のものです。大文字と小文字は区別されます。

TvAIrをインターネットへ直接公開する用途は想定していません。ルーター等でTvAIrの待受ポートをインターネットへ直接公開しないでください。

## プラグイン

TvAIr対応プラグインを追加することで、TvAIr本体の機能を拡張できます。

プラグインによっては、TvAIrの設定画面で追加の許可や設定が必要です。外部情報を利用するプラグインについても、TvAIr側のネットワーク設定とプラグインごとの許可に従って動作します。

各プラグイン固有の導入方法・設定方法は、それぞれの配布物に含まれるREADMEを確認してください。

## 録画中断時の扱い

録画中にWindowsのスリープ、TvAIrの終了、PCの再起動などによって録画処理が失われた場合、その録画は失敗として終了します。

その後も録画可能な時間が残っている場合は、欠損した区間を失敗として確定したうえで、残り区間を別の録画として再開する場合があります。

## 録画終了後の電源操作

録画終了後にスリープまたはシャットダウンする設定では、最後に残っている録画が正常に完了した場合に電源操作の待機へ入ります。

次の場合は電源操作を行いません。

- 録画を手動で停止した場合
- 録画が失敗した場合
- 待機中に別の録画やEPG取得が始まった場合
- TvAIrで視聴中の場合
- 次の録画やEPG取得に必要な起床準備時間へ入った場合

## 更新方法

旧バージョンから更新する場合は、次の手順を推奨します。

1. 録画中、EPG取得中、視聴中でないことを確認します。
2. TvAIrを終了します。
3. 現在使用しているTvAIrフォルダを必要に応じてバックアップします。
4. 新しいバージョンを同じアーキテクチャでReleaseビルドします。
5. 新しいビルド出力でアプリ本体を更新します。
6. TvAIrを起動し、設定、番組表、予約一覧、録画保存先を確認します。
7. 可能であれば短いテスト録画を行ってください。

更新時に設定や既存データを初期化する必要はありません。既存環境を保持したまま更新する場合でも、重要な設定やデータは事前にバックアップしておくことを推奨します。

## 注意事項

録画予約を登録した後は、予約一覧と録画保存先を確認してください。チューナー構成、BonDriver、TVTest、録画保存先などを変更した場合は、短いテスト録画で動作確認することを推奨します。

- 録画処理が中断した場合の状態確定と、録画可能時間が残っている場合の復旧処理を改善しました。

- チェーン予約の番組境界処理を改善しました。
- 定時EPG取得の計画と録画予約との調整を改善し、取得済み番組に対する自動検索予約処理も効率化しました。
- 録画前の番組情報確認と録画中の番組情報追従を改善しました。
- 録画用と視聴用でTVTestを分けて設定できるよう改善しました。
- 視聴用TVTestの終了検出と視聴チューナーの解放を改善しました。
- プラグインからの視聴予約、外部情報利用、独立ウィンドウ、状態更新などに対応する機能を拡張しました。
- ネットワーク利用のON/OFFとLAN接続設定を整理し、初期状態をネットワーク利用OFFとしました。
- 長時間連続利用時に不要な状態や描画資源が残り続けないよう、各種ライフサイクルを改善しました。
- タスクトレイ、番組表、予約一覧、検索、設定、ログ、ヘルプ、ライト／ダークテーマなどの表示と操作性を改善しました。

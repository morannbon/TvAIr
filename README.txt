# TvAIr 1.2.16

## v1.2.16 の更新内容

- **録画前EPG確認（PreRec）の担当管理を根本的に修正しました。** 別のEPG取得が動いても予約ごとの担当が変わらないようにしました。予約一覧にも実際の取得予定を正しく表示します。
- TVTestのチャンネル設定でサービスタイプが空欄でも有効な局を認識できるようにしました。
- EPG取得と録画失敗時の案内を改善しました。録画前EPG確認を含めて原因に応じた内容を画面とログに表示します。
- 「報告用コピー」とログの安全性を改善しました。長い記録も一度にコピーできます。個人情報の保護も強化しました。
- その他軽微な修正。

**以前のバージョンから更新する場合：** TvAIrの設定メニューで「TVTest」を開いてください。「連携するTVTestプラグインフォルダ」にTVTest内の `Plugins` フォルダを指定して保存してください。

## 製品説明

TvAIrはTVTestを利用したWindows向けの番組表・録画・視聴アプリです。

番組表からの録画予約や自動検索予約に対応します。放送時間の変更への追従も行います。

複数チューナーとプラグインを利用できます。

## 動作環境

### 実行環境

- Windows 10 / Windows 11（x64 / x86対応）
- .NET 8 Desktop Runtime
- Microsoft Visual C++ 再頒布可能パッケージ
- TVTest 0.10.0以降
- 使用するBonDriverとTVTest用 `.ch2` ファイル
- 対応チューナーと受信設備
- B25Decoder.dllまたは利用環境に応じた復号環境
- 録画ファイルを保存する空き容量

`ChSet.txt` は任意です。空欄の場合は選択したBonDriver名に対応する `.ch2` を読み込みます。

### ビルド環境

- Visual Studio 2022
- C++によるデスクトップ開発
- Windows SDK
- .NET 8 SDK

## ビルド・配置

1. ソースZIPを展開して `TvAIr.sln` をVisual Studio 2022で開きます。
2. `Release` を選択します。使用環境に合わせて `x64` または `x86` でソリューション全体をビルドします。
3. ビルドしたファイルを依存DLLやWeb表示用ファイルとともに配置します。フォルダ構成は維持してください。
4. 録画用の `TvAIrEpgRec.exe` と必要な依存ファイルも配置します。
5. `TvAIr.exe` を起動してTVTest・BonDriver・チャンネル・録画保存先を設定します。
6. EPGを取得して番組表を確認します。視聴と録画の動作も確認してください。

ビルド対象は次の4プロジェクトです。

- `TvAIrEpgRec`
- `AribDecodeBridge`
- `TvAIrPlugin`
- `TvAIr`

主なビルド出力先は次のとおりです。

- x64：`TvAIr\bin\x64\Release\net8.0-windows\`
- x86：`TvAIr\bin\x86\Release\net8.0-windows\`

`B25Decoder.dll` を使用する場合はTvAIrと同じアーキテクチャのものを `TvAIr.exe` と同じフォルダへ配置してください。

TVTestフォルダに `winscard.dll` がある場合はそのファイルを使用します。ない場合はWindows標準のカードリーダー機能を使用します。

ビルド不要の実行用ZIPでは同梱の `INSTALL.txt` も確認してください。

## 基本的な使い方・設定

### 録画予約

番組表から録画予約を追加できます。

プログラム予約・自動検索予約・チェーン予約に対応します。

自動検索予約ではルールごとに次の項目を設定できます。

- 現在のサービスのみ保存する
- 字幕データを保存する

### チェーン予約

設定の「チェーン予約」から次の方式を選択できます。

- 無効
- 手動
- 自動

自動チェーンでは同じ局で終了時刻と開始時刻が一致する予約を接続します。

録画中の「今すぐ録画」も条件を満たせば接続対象になります。

チェーン予約の各番組は別々のTSファイルへ保存します。

自動チェーンでは先頭番組から最後まで(C)を表示します。手動チェーンでは2番組目から最後まで表示します。

方式を切り替えても作成済みのチェーンは残ります。表示と予約取消は現在選択中の方式に従います。

### EPG取得と放送時間の追従

定時EPG取得は録画予約との重複に応じて開始時刻を調整します。

録画前と録画中に番組情報を確認します。放送開始時刻や終了時刻が変更された場合は録画予定へ反映します。

### 視聴

録画用と視聴用で別のTVTestを利用できます。

視聴専用のTVTestを使用する場合は「視聴用TVTest.exe のフルパス」を設定してください。

TvAIrを終了・再起動しても視聴中のTVTestは終了しません。

再起動後に視聴を開始すると新しいTVTestを起動します。「視聴停止」は操作対象のTVTestを終了します。

### チャンネル設定

`ChSet.txt` を空欄にした場合は選択したBonDriverと同じ名前の `.ch2` を使用します。

`.ch2` はBonDriverフォルダから探します。見つからない場合はTVTestフォルダを探します。

TVTestでチャンネルを再スキャンして `.ch2` を更新すると局名と選局情報を更新できます。

ChSet.txtの使用有無を切り替えた場合は設定を保存してTvAIrを再起動してください。

ONID・TSID・SIDが変わった場合はEPGを再取得して既存予約を確認してください。旧番号の予約は自動移行しません。

### CATV

CATV対応のBonDriverを利用できます。

チューナー設定で「CATV」を選択できます。従来の「地デジ/BS/CS」設定で動作している環境も引き続き利用できます。

局は地上波・BS・CS・CATVに分類して表示します。

### ネットワーク利用

「ネットワーク利用」の初期状態はOFFです。

OFF時はLANとインターネットへの通信を行いません。TvAIrはこのPC内で使用できます。

LAN内の端末から接続する場合は次の設定が必要です。

1. 「ネットワーク利用」をONにします。
2. 「LANからの接続を許可する」をONにします。
3. 12文字以上の接続用パスワードを設定して保存します。

パスワードは大文字と小文字を区別します。

インターネットへ直接ポートを公開しないでください。

外部情報を利用するプラグインには「ネットワーク利用」のONに加えてプラグインごとのインターネット利用許可が必要です。

「ネットワーク利用」がOFFの場合は下位の許可設定にかかわらず外部通信を停止します。

## 更新方法

1. 録画・EPG取得・視聴が実行中でないことを確認してTvAIrを終了します。
2. 必要な設定・予約・録画履歴をバックアップします。
3. 使用環境と同じアーキテクチャでビルドした新しいファイル群へ差し替えます。
4. TvAIrを起動してチューナー設定・番組表・予約リスト・録画保存先を確認します。
5. 短いテスト録画を行ってください。

v1.2.0～v1.2.2から更新した場合は設定の自動移行に伴い再起動案内が表示されることがあります。その場合は案内に従って再起動してください。

## 注意事項

- CATV（ISDB-C）は使用するチューナーやBonDriverによって動作条件が異なります。
- チューナー・BonDriver・TVTest・カード・チャンネル設定により動作が変わります。復号に失敗すると暗号化されたまま録画される場合があります。「現在のサービスのみ保存する」で録画した未復号ファイルは後から復号できない場合があります。
- 録画の開始・終了追従は放送波の番組情報と受信状況に依存します。重要な予約は事前に確認してください。
- 録画中断後に録画可能時間が残っていれば別ファイルで再開する場合があります。手動停止や録画失敗時には設定済みの録画終了後の電源操作は行われません。
- TvAIrの使用による録画失敗やデータ損失等について作者は責任を負いません。

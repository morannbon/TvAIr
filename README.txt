TvAIr 1.2.0 README

1. 概要

TvAIrは、TVTest環境を利用して番組表表示、録画予約、自動検索予約、視聴、プラグイン連携を行うアプリケーションです。

主な機能:
- 番組表表示
- 録画予約、プログラム予約、チェーン予約
- キーワード検索、自動検索予約
- 録画状態と予約状態の確認・操作
- TVTestを使用した視聴
- プラグイン対応
- ライト／ダークテーマ

2. 必要環境

実行環境:
- Windows 10 / 11
- .NET 8 Desktop Runtime
- Microsoft Visual C++ 再頒布可能パッケージ
- TVTest 0.10.0以降を使用できる環境
- B25デコーダーまたは復号に必要な環境
- 使用するBonDriver
- .ch2ファイル
- ChSet.txt
- 録画保存先

ビルド環境:
- Visual Studio 2022
- .NET 8 SDK
- C++によるデスクトップ開発

3. ビルド方法

1. Visual Studio 2022でTvAIr.slnを開きます。
2. 構成をReleaseにします。
3. 使用する環境に合わせてx64またはx86を選択します。
4. ソリューションをビルドします。

製品ソリューション:
- TvAIrEpgRec
- AribDecodeBridge
- TvAIrPlugin
- TvAIr

4. インストール方法

1. 使用するアーキテクチャのビルド出力を任意のフォルダへ配置します。
2. B25Decoder.dllをTvAIr.exeと同じフォルダに配置します。
3. TvAIr.exeを起動します。
4. 設定画面で基準となるTVTest、BonDriver、.ch2、ChSet.txt、録画保存先を指定します。
5. 番組表を取得します。

録画用と視聴用でTVTestを分けない場合は、基準となるTVTestを共通で使用します。視聴専用のTVTestを別に使用する場合は、設定画面の「視聴用TVTest.exe のフルパス」を指定します。

5. ネットワーク接続

初期状態では、このPCからだけTvAIrを開けます。

同じLAN内の端末から利用する場合は、設定画面の「ネットワーク」で次を設定します。

- 「LANからの接続を許可する」を有効にする
- 12文字以上の接続用パスワードを設定する
- 設定を保存する

接続用パスワードは英字・数字・記号などの文字種に必須条件はなく、大文字と小文字は区別されます。Windowsのユーザー名やパスワードとは別のものです。インターネットへポートを直接公開しないでください。

6. チェーン予約

チェーン予約は、同じ放送局で連続する複数の番組を同じ録画用チューナーで順番に録画します。番組の境界では前の録画を終了してチューナーを解放し、その後に次の録画へ引き継ぎます。前後の録画マージンが重なる場合は後番組を優先し、対象となる前番組名には「(C)」を表示します。

7. 録画中断時の扱い

録画中にWindowsのスリープやTvAIr／PCの再起動などで録画処理が実際に失われた場合、その録画は失敗として終了します。録画可能時間が残っている場合は、元の欠損区間を失敗として確定したうえで、別予約・別TSとして残り区間の録画を再開します。

8. 録画終了後の電源操作

録画終了後にスリープまたはシャットダウンする設定では、最後に残っている録画が正常完了した場合だけ電源操作の待機を開始します。手動停止や録画失敗で終了した場合は実行しません。待機中に別の録画やEPG取得が動作した場合、TvAIrで視聴中の場合、または次の録画・EPG取得の起床準備時間に入った場合も電源操作を行いません。

TvAIr Alpha 1.1.0

- 録画ファイル名の生成をTVTestの設定に沿うよう調整しました。
- TVTest.ini の RecordFileName で使う日時や番組名などの置換に対応しました。
- 録画ファイル名の文字変換を整理しました。
- 番組タイトルのARIB文字サイズ制御に対応し、中型英数字の表示をTVTestに近づけました。
- プログラム予約の時刻入力で、時・分の指定欄が並んで表示されるよう修正しました。
- 設定画面のジャンル色プリセットが設定画面の前面に表示されるよう修正しました。
- GitHub clone 後のソリューションビルド順を安定させるため、TvAIr と録画ワーカーの依存関係を整理しました。
